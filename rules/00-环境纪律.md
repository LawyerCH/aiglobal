# 全局开发环境纪律

## 运行时版本
- 所有语言运行时由 mise 统一管理（全局基线见 `~/.config/mise/config.toml`：node 24 / python 3.12）
- 新项目用 `mise use node@X python@Y` 把版本写进项目 `mise.toml`，不要手动指定或另外安装运行时
- 不要改用 nvm / volta / asdf 等其他版本管理器（已统一到 mise）

## 依赖安装
- **Node**：只用 `pnpm`；禁止 `npm i -g`，禁止全局安装
- **Python**：只用 `uv`（`uv sync` / `uv add`），依赖装在项目内 `.venv`；禁止全局 `pip install`
- **其他语言**：优先项目内隔离
- 禁止用 `sudo` 安装任何语言包或运行时
- 装依赖前先查看是否有 lockfile（`pnpm-lock.yaml` / `uv.lock`），有则用锁定安装（`pnpm install --frozen-lockfile` / `uv sync --frozen`）
- 装完依赖后，报告「装了哪些包 + 大约占用多少磁盘」

## 磁盘纪律
- 不在每个项目重复下载运行时，不把依赖装到全局
- 优先复用共享缓存（pnpm store / uv cache）
